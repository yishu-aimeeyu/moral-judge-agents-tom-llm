# A second, independent child anchor — the open ToM booklet dataset

Built by `code/experiments/69_children_ingest.py`. Everything in this directory is regenerated by
that script; nothing here is hand-maintained, and `raw/` is the untouched download.

Reading the workbooks needs `openpyxl` (`pip install openpyxl`). Note that
`code/requirements.txt` is committed but empty, so the install line in the top-level README will
not provide it.

```
python code/experiments/69_children_ingest.py --fetch    # download from OSF (idempotent)
python code/experiments/69_children_ingest.py --build    # derive the tables below
python code/experiments/69_children_ingest.py --build --first-session-only   # sensitivity
python code/experiments/69_children_ingest.py --plot     # comparison figure
```

## Why bother, when a child anchor already exists

The existing anchor (`../cushman_child_bands_*.csv`) is digitized off Cushman et al. (2013)
Fig. 3. Its values carry read error of roughly ±0.03–0.05, it cannot be re-binned, and it cannot
carry a confidence interval. This dataset is item-level and raw, from a different sample, with
different stimuli and a different response format, so the same developmental quantity can be
computed with real n per bin and real intervals. **Nothing here replaces the Cushman anchor** —
no existing figure or CSV was modified — and the comparison figure plots both.

## Item selection

Included: `Concept-super == "Moral Reasoning"`, `Qtype == "2AFC"`. Explanation-type moral items
exist and are coded 0/1, but free-response coding is a different measurement and is left out.
The source's own exclusion flags are honoured, not reimplemented: an observation is used only if
`Include? == 1`, `Exp Error? == 0`, and the answer is 0 or 1 (the sheets also contain `NA`).
60 observations are dropped by those flags.

The booklet asks the same two blame questions in two belief frames, which is what makes it usable
here:

| frame | scenario | question | correct |
|---|---|---|---|
| false belief | Allie takes Sue's snack **believing it is her own** | Is Allie being mean/naughty? | No |
| false belief | " | Should Allie get in trouble? | No |
| true belief | Melanie eats Mitch's cookie **knowing it is his** | Is Melanie being mean/naughty? | Yes |
| true belief | " | Should Melanie get in trouble? | Yes |

**naughty items are a wrongness judgment; trouble items are a punishment judgment.** That is the
same split Cushman's *Naughty* and *Punish* series draw, so both series are produced here and
`../methods_child_measure.md`'s argument for preferring the wrongness series carries over
unchanged. Item-level accuracy for all 12 moral 2AFC items by age band is in
`children_moral_item_accuracy.csv`.

### Two item categories deliberately excluded from the anchor

Both are still reported at item level; they are excluded from the derived anchor only.

* **Restitution.** `ToMS_2AFC_16.9` reads *"Now Mitch has a cookie. Should Melanie **still** get
  in trouble?"* This asks whether compensating the victim cancels desert, which is not the same
  question as whether the act deserves punishment. It matters: pooling it into the punishment
  series pulled that series' accuracy down to 0.18 at age 3, against 0.72 for the plain trouble
  item in the same children, and would have turned a restitution effect into what looked like a
  developmental story about intent.
* **Third-party anger.** *"Is it fair that mother is mad with J?"*, *"Is J mad at Isa?"* and
  *"Is mother mad at Isa?"* are judgments about another person's emotional reaction, not the
  child's own blame attribution.

## Normalization, and the one place it must not be over-read

Responses are binary correct/incorrect, so accuracy has to be turned into a blame proportion. On
a false-belief (accidental-type) act the child who answers **correctly** is the one who
exculpates, so the child who attributes blame is the one who answers incorrectly:

```
blame_accidental  = 1 − accuracy(false-belief items)
blame_intentional =     accuracy(true-belief items)
contrast          = blame_intentional − blame_accidental
```

Three limits on comparing this with the Cushman bands, in decreasing order of importance:

1. **It is a different contrast.** Cushman's child bands give **attempted − accidental**: intent
   without harm, against harm without intent. The booklet's intent limb is **intentional** harm —
   intent and harm together — so this anchor measures **intentional − accidental**, the other
   diagonal of the 2×2. It is a genuine intent-based blame contrast and it is developmentally
   informative, but it is not a substitute for the attempted−accidental number and no column
   here is named as though it were.
2. **It is a proportion of children, not a mean rating.** A forced choice gives the fraction of
   children who blame; Cushman's series are mean normalized blame magnitudes on a rating scale.
   Comparing the two anchors compares shapes, not units.
3. **Only Booklet 2 has true-belief moral items**, so the intent limb rests on far fewer
   observations (n = 15–55 per band) than the accidental limb (n = 18–203). The per-point n is in
   every row of `children_child_anchor.csv`, and the figure carries 95% Wilson intervals — Wilson
   rather than normal because several bands are small and near the ceiling.

## Sample restrictions

* **Neurotypical children only** in the anchor. The 68 autistic children are parsed and counted
  but excluded, because the anchor is used as a typical-development reference. Booklet 1's sheet
  carries the `ASD Diagnosis` flag; Booklet 2's sheet has no such column and its cohorts are
  neurotypical.
* **Longitudinal repeats are handled two ways rather than assumed away.** `LongID` is a
  cross-booklet pointer: a Booklet 1 participant whose `LongID` is `Booklet2-030` is the same
  child, seen again at an older age. The primary tables use all 385 sessions, since each is a
  valid age–accuracy observation; the `*_first_session_only.csv` variants keep one session per
  child (n = 321). **The largest resulting shift in any band's contrast is 0.047**, so the
  non-independence does not carry the developmental result.
* Age is the source's own continuous `Age` in years. Bands reuse Cushman's boundaries exactly
  (4–5, 6–7, 8+) so the two anchors are binned identically; `child_3` is reported additionally
  because this dataset reaches younger than Cushman's does, at small n.

## What the two anchors say about each other

Read as shapes, since the units differ. On the **wrongness** series the accidental limb agrees
closely and independently: booklet 0.398 / 0.142 / 0.010 across the 4–5, 6–7 and 8+ bands against
digitized Cushman 0.455 / 0.200 / 0.060. Two different samples, stimulus sets and response formats
produce the same steep decline in blaming the false-belief actor, which is a stronger footing for
the developmental claim than a digitized figure alone.

On the **punishment** series they diverge, and the divergence is informative rather than a
discrepancy to resolve: the booklet's children exculpate far more readily (0.333 / 0.149 / 0.035)
than Cushman's punishment ratings suggest (0.590 / 0.415 / 0.220). Cushman's central finding is
that punishment stays outcome-based longer than wrongness does, and a binary "should she get in
trouble?" is a much weaker test of that than a graded punishment rating. This is a further reason
to keep the wrongness series as the anchor, which is what `../methods_child_measure.md` already
argues on construct-matching grounds.
