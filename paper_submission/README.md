# Overleaf-ready manuscript package

## Contents

- `main.tex`: integrated manuscript
- `supplement.tex`: auditable result inventory and robustness details
- `references.bib`: cited bibliography
- `figures/`: generated and copied source figures
- `generated/result_tables.tex`: tables generated from authoritative CSV files
- `scripts/build_assets.py`: reproducible asset-generation script
- `CLAIM_EVIDENCE.md`: claim-to-source audit
- `LITERATURE_AUDIT.md`: live verification links for cited literature
- `PAPER_FRAMEWORK.md`: research questions, section logic, innovations, and difficulties
- `VENUE_ADAPTATION.md`: venue-specific adaptation plan
- `ASSET_MANIFEST.md`: figure and table provenance

## Local build

From this directory:

```bash
python scripts/build_assets.py
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

If `latexmk` is unavailable:

```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

## Overleaf

1. Create a blank project.
2. Upload the full contents of `paper_submission/`, preserving the `figures/` and `generated/` directories.
3. Set `main.tex` as the main document.
4. Use pdfLaTeX.

The generated assets are already included, so Python is not required on Overleaf.
