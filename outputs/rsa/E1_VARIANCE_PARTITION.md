## Headline — pre-registered `primary` variant

- **P1 (outcome unique ρ² > intent unique ρ² at relative depth ≥ 0.75)**: **undecidable** — every layer was excluded by P4 (surface-dominated), so the comparison set is empty in this variant. This is not evidence in either direction.
- **P2 (same ordering at each model's own peak-intent layer)**: **undecidable** — every layer was excluded by P4 (surface-dominated), so the comparison set is empty in this variant. This is not evidence in either direction.
- **P4** (surface control) excluded **24** model×layer cell(s) as lexical-dominated. TF-IDF distance between these vignettes is nearly the scenario-identity matrix, which is why: see amendment 1.

## Amendment 1 — `lexical_resid` variant (P4 still applied)

Lexical distance residualised on scenario identity.

- **P1 at relative depth ≥ 0.75**: **undecidable** — every layer was excluded by P4 (surface-dominated), so the comparison set is empty in this variant. This is not evidence in either direction.
- **P2 at the peak-intent layer**: **undecidable** — every layer was excluded by P4 (surface-dominated), so the comparison set is empty in this variant. This is not evidence in either direction.

Residualising does not rescue the control: the intent and outcome manipulations are *realised lexically* in these vignettes — within a scenario group the four conditions differ by the clause that makes the act intended or the harm occur — so a fine-grained word-overlap predictor captures more unique variance than the binary factor it expresses. That is a property of the stimulus design, not of the models. See amendment 2.
